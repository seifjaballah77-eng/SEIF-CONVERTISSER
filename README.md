# SEIF CONVERTISSER

واجهة ويب عربية RTL لإدارة الوسائط، مع قائمة جانبية وصفحات مستقلة للأدوات.

## الملفات
- `index.html` — هيكل التطبيق.
- `styles.css` — تصميم OLED داكن ومتجاوب.
- `app.js` — التنقل، سجل الروابط المحلي (30 يوماً)، نسخ الروابط، طابور الروابط، إعدادات الواجهة وربط API.

## النشر على GitHub Pages
1. افتح Settings → Pages.
2. اختر Deploy from a branch.
3. اختر الفرع `main` والمجلد `/(root)`.
4. احفظ وانتظر اكتمال النشر.

## خادم المعالجة
الواجهة تدعم عنوان Backend من صفحة الإعدادات. مسارات المعالجة المتوقعة:
- `POST /api/process/trim`
- `POST /api/process/audio`
- `POST /api/process/convert`
- `POST /api/process/compress`
- `POST /api/process/gif`
- `GET /api/search?q=...&platform=...`

لا يتم تضمين موصلات تتجاوز حماية المنصات أو قيود الوصول. يجب إعداد موصلات بحث وتنزيل متوافقة مع شروط المنصات، وإتاحة المحتوى الذي يملكه المستخدم أو يملك إذناً باستخدامه.

## ملاحظات
هذه هي النسخة الأولى للواجهة (Frontend). لا تدّعي تنزيل محتوى المنصات أو تنفيذ FFmpeg قبل نشر وربط Backend فعلي. سجل الروابط محلي في المتصفح لمدة 30 يوماً، ولا يخزن ملفات الفيديو.
